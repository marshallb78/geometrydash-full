# Geometry Dash - Full Web Edition 🚀

A full, authentic, browser-playable version of **Geometry Dash** powered by Phaser and HTML5. Play directly in your browser with no installation required!

🎮 **Play Online**: [https://marshallb78.github.io/geometrydash-full/](https://marshallb78.github.io/geometrydash-full/)

---

## 🌟 Features

- **All Official Levels**: Includes Stereo Madness, Back On Track, Polargeist, Dry Out, Base After Base, Can't Let Go, Jumper, Time Machine, Cycles, xStep, Clutterfunk, Theory of Everything, Electroman Adventures, Clubstep, Electrodynamix, Hexagon Force, Blast Processing, Theory of Everything 2, Geometrical Dominator, Deadlocked, Fingerdash, Dash, and Bloodbath!
- **Complete Game Modes & Physics**: Sub-stepped physics engine supporting:
  - 🟩 Cube (Standard jump & jump pads/rings)
  - 🚀 Ship (Smooth hold-to-fly gravity)
  - ⚪ Ball (Gravity flip mechanics)
  - 🛸 UFO (Flappy jump impulses)
  - 🌊 Wave (Zig-zag diagonal movement with trail)
  - 🤖 Robot (Hold-to-jump variable height)
  - 🕷️ Spider (Instant teleportation)
- **Official Soundtrack & SFX**: Full high-fidelity original soundtracks by Waterflame, DJVI, ForeverBound, F-777, and more.
- **Level Editor**: Built-in level editor to create, test, and export your own levels.
- **Macro Recorder & Replay**: Record your runs and replay them with frame-accurate input tracking.
- **Full Screen & Responsive**: Adapts cleanly to any display without sprite stretching or distortion.

## 🌐 Running Locally

To run this game locally on your computer:

```bash
# Clone the repository
git clone https://github.com/marshallb78/geometrydash-full.git
cd geometrydash-full

# Start a local static server (Node.js example)
node tools/server.js
```

Then open your browser to `http://localhost:8080/`.

---

## 🚀 GitHub Pages Deployment

This repository is pre-configured for GitHub Pages:
1. Go to your repository on GitHub: `https://github.com/marshallb78/geometrydash-full`
2. Click **Settings** ➔ **Pages** (in the left sidebar).
3. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **`main`** / Folder: **`/ (root)`**
4. Click **Save**.
5. Within 1-2 minutes, your game will be live at:
   👉 **`https://marshallb78.github.io/geometrydash-full/`**
